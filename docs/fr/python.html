L’exemple Python, étape par étape

Cette page est le cœur computationnel de NeuralMath. Le code est assez court pour être lu entièrement, mais assez complet pour montrer comment un réseau de neurones apprend réellement.

Download PythonGoogle ColabGitHub

1. Données : un domaine large mais contrôlé

Le jeu d’entraînement contient 64 points et le jeu de test illustratif en contient 8. Les points sont synthétiques, mais les valeurs de masse et de diamètre restent dans des plages plausibles. Une courbe de référence lisse sert uniquement à produire une géométrie non triviale ; elle n’est pas fournie au réseau.

def base_boundary(m):
    return (
        6.68
        + 0.74 * np.exp(-((m - 155) / 20) ** 2)
        + 1.50 / (1 + np.exp(-(m - 202) / 5))
    )

X_train = np.vstack([a1, a2, l1, l2])
y_train = np.array([1.0] * 32 + [0.0] * 32)

2. Standardisation

La masse et le diamètre vivent sur des échelles numériques différentes. La moyenne et l’écart-type du jeu d’entraînement sont donc utilisés pour transformer à la fois les données d’entraînement et de test. Les données de test ne déterminent jamais les paramètres de normalisation.

mean = X_train.mean(axis=0)
std = X_train.std(axis=0)
Xn = (X_train - mean) / std

3. Architecture : 2–12–1

Deux entrées alimentent une couche cachée de douze neurones ReLU, suivie d’une sortie sigmoïde. On obtient ainsi 49 paramètres entraînables. La couche cachée est assez expressive pour représenter une frontière visiblement non linéaire tout en restant facile à inspecter.

rng = np.random.default_rng(42)
W1 = 0.1 * rng.standard_normal((12, 2))
b1 = np.zeros(12)
W2 = 0.1 * rng.standard_normal(12)
b2 = 0.0

4. Propagation avant

Pour chaque entrée, le réseau calcule une transformation affine, applique ReLU, combine les activations cachées puis applique la sigmoïde. C’est le chemin de la prédiction.

z1 = W1 @ x + b1
h = relu(z1)
z2 = W2 @ h + b2
y_hat = sigmoid(z2)

5. Rétropropagation

Le code dérive la perte quadratique à travers la sigmoïde puis à travers la couche ReLU. Aucun système de différentiation automatique n’est utilisé : la règle de la chaîne apparaît explicitement dans le programme.

delta2 = (y_hat - target) * y_hat * (1 - y_hat)
dW2 = delta2 * h
db2 = delta2

delta1 = (delta2 * W2) * relu_derivative(z1)
dW1 = np.outer(delta1, x)
db1 = delta1

6. Descente de gradient stochastique

À chaque époque, les exemples sont mélangés. Les paramètres sont mis à jour après chaque exemple et la perte moyenne d’entraînement est recalculée, paramètres fixés, à la fin de l’époque.

for epoch in range(n_epochs):
    for i in rng.permutation(len(Xn)):
        # forward pass, backpropagation, update
        W1 -= learning_rate * dW1
        b1 -= learning_rate * db1
        W2 -= learning_rate * dW2
        b2 -= learning_rate * db2

7. La frontière de décision apprise

Après l’entraînement, le code évalue le réseau sur une grille dense du plan masse–diamètre. Le niveau ŷ = 0,5 devient la frontière de décision. Tous les points d’entraînement restent visibles sur la figure.

masses = np.linspace(116, 214, 500)
diameters = np.linspace(6.0, 8.85, 500)
M, D = np.meshgrid(masses, diameters)
grid = np.column_stack([M.ravel(), D.ravel()])
P = predict(grid, mean, std, W1, b1, W2, b2).reshape(M.shape)

ax.contour(M, D, P, levels=[0.5], linewidths=2.2)

Une graine fixe rend l’expérience déterministe dans l’environnement NumPy documenté. Le même script produit la figure distribuée avec le projet.
