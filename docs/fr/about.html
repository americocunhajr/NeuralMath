À propos de NeuralMath

Un projet éducatif ouvert et multilingue reliant les mathématiques des réseaux de neurones à un code transparent et reproductible.

Project

Le projet a été créé par Americo Cunha Jr comme compagnon computationnel de textes pédagogiques consacrés à la structure mathématique des réseaux de neurones. Le site est volontairement centré sur le code : l’exposé long est distribué en PDF, tandis que la couche web privilégie la navigation, la reproductibilité, l’explication de l’implémentation et les futures extensions computationnelles.
