Réseaux de neurones, des équations au code

Lisez le réseau de neurones directement dans le code Python.

NeuralMath est une introduction multilingue aux réseaux de neurones centrée sur le code. Le site explique pas à pas une implémentation complète avec NumPy ; les textes pédagogiques plus développés sont proposés séparément au format PDF.

Un exemple, étudié en profondeur

Le site est volontairement organisé autour d’un unique programme reproductible. Chaque partie du code est reliée à l’idée mathématique qu’elle met en œuvre, sans transformer les pages web en un second manuel.

Le code d’abord

Commencez par le programme exécutable et parcourez les données, la standardisation, l’architecture, la propagation avant, la rétropropagation, l’entraînement et la visualisation.

La pédagogie en PDF

Les explications mathématiques longues se trouvent dans les PDF afin que le site reste concis et utile comme compagnon computationnel.

Conçu pour évoluer

Les futurs modules pourront réutiliser la même structure pour la classification multiclasse, les réseaux plus profonds, la vérification des gradients, l’optimisation et les démonstrations interactives.
