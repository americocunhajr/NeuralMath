El ejemplo en Python, paso a paso

Esta página es el núcleo computacional de NeuralMath. El código es lo bastante pequeño para leerse por completo y lo bastante completo para mostrar cómo aprende realmente una red neuronal.

1. Datos: un dominio amplio pero controlado

El conjunto de entrenamiento contiene 64 puntos y el conjunto de prueba ilustrativo contiene 8. Los puntos son sintéticos, pero la masa y el diámetro se mantienen en rangos plausibles. Una curva suave de referencia se usa solo para generar una geometría no trivial; la red no recibe esa curva.

def base_boundary(m):
    return (
        6.68
        + 0.74 * np.exp(-((m - 155) / 20) ** 2)
        + 1.50 / (1 + np.exp(-(m - 202) / 5))
    )

X_train = np.vstack([a1, a2, l1, l2])
y_train = np.array([1.0] * 32 + [0.0] * 32)

2. Estandarización

La masa y el diámetro tienen escalas numéricas diferentes. Por ello, la media y la desviación estándar del conjunto de entrenamiento se usan para transformar tanto entrenamiento como prueba. Los datos de prueba no determinan los parámetros de normalización.

mean = X_train.mean(axis=0)
std = X_train.std(axis=0)
Xn = (X_train - mean) / std

3. Arquitectura: 2–12–1

Dos entradas alimentan una capa oculta con doce neuronas ReLU, seguida de una salida sigmoide. Esto produce 49 parámetros entrenables. La capa oculta tiene capacidad suficiente para representar una frontera visiblemente no lineal sin dejar de ser fácil de inspeccionar.

rng = np.random.default_rng(42)
W1 = 0.1 * rng.standard_normal((12, 2))
b1 = np.zeros(12)
W2 = 0.1 * rng.standard_normal(12)
b2 = 0.0

4. Propagación hacia delante

Para cada entrada, la red calcula una transformación afín, aplica ReLU, combina las activaciones ocultas y finalmente aplica la sigmoide. Ese es el camino de la predicción.

z1 = W1 @ x + b1
h = relu(z1)
z2 = W2 @ h + b2
y_hat = sigmoid(z2)

5. Retropropagación

El código deriva la pérdida cuadrática a través de la sigmoide y después de la capa ReLU. No se usa diferenciación automática: la regla de la cadena aparece explícitamente en el programa.

delta2 = (y_hat - target) * y_hat * (1 - y_hat)
dW2 = delta2 * h
db2 = delta2

delta1 = (delta2 * W2) * relu_derivative(z1)
dW1 = np.outer(delta1, x)
db1 = delta1

6. Descenso de gradiente estocástico

En cada época se barajan los ejemplos. Los parámetros se actualizan después de cada ejemplo y la pérdida media de entrenamiento se recalcula con los parámetros fijos al final de la época.

for epoch in range(n_epochs):
    for i in rng.permutation(len(Xn)):
        # forward pass, backpropagation, update
        W1 -= learning_rate * dW1
        b1 -= learning_rate * db1
        W2 -= learning_rate * dW2
        b2 -= learning_rate * db2

7. La frontera de decisión aprendida

Después del entrenamiento, el código evalúa la red en una malla densa del plano masa–diámetro. El nivel ŷ = 0,5 se convierte en la frontera de decisión. Todos los puntos de entrenamiento permanecen visibles en la figura.

masses = np.linspace(116, 214, 500)
diameters = np.linspace(6.0, 8.85, 500)
M, D = np.meshgrid(masses, diameters)
grid = np.column_stack([M.ravel(), D.ravel()])
P = predict(grid, mean, std, W1, b1, W2, b2).reshape(M.shape)

ax.contour(M, D, P, levels=[0.5], linewidths=2.2)
