Redes neuronales, de las ecuaciones al código

Lee la red neuronal directamente en el código Python.

NeuralMath es una introducción multilingüe y centrada en el código a las redes neuronales. El sitio explica paso a paso una implementación completa en NumPy; los textos pedagógicos extensos se ofrecen por separado en PDF.

Un ejemplo, examinado en profundidad

El sitio está organizado deliberadamente alrededor de un único programa reproducible. Cada parte del código se conecta con la idea matemática que implementa, sin convertir las páginas web en un segundo libro de texto.

Primero el código

Empieza por el programa ejecutable y recorre datos, estandarización, arquitectura, propagación hacia delante, retropropagación, entrenamiento y visualización.

Pedagogía en PDF

Las explicaciones matemáticas extensas viven en los PDF, de modo que el sitio permanece conciso y útil como compañero computacional.

Preparado para crecer

Los futuros módulos podrán reutilizar la misma estructura para clasificación multiclase, redes más profundas, comprobación de gradientes, optimización y demostraciones interactivas.
