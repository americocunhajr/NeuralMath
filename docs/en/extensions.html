Roadmap

Future extensions

NeuralMath is designed as a sequence of computational modules. New examples should preserve the same principle: a small, readable program with a precise explanation of what each block computes.

Module 1 · current

Binary classification

The present NumPy network: data generation, standardization, ReLU hidden layer, sigmoid output, explicit backpropagation and decision regions.

Module 2

Training dynamics

Loss curves, snapshots of the decision boundary during training, and the role of the learning rate.

Module 3

Inside the hidden layer

Visualize what individual ReLU neurons contribute to the final boundary.

Module 4

Multiclass networks

Replace the sigmoid by softmax and move from two fruit classes to several categories.

Module 5

Gradient checking

Compare hand-derived gradients with finite differences as a reproducibility and debugging exercise.

Module 6

Deeper networks

Add a second hidden layer and show what changes mathematically—and what does not.

Interactive layer

Browser playground

A later interactive module can let readers move points, change hidden neurons and learning rates, and watch the decision boundary respond.
