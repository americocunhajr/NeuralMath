Das Python-Beispiel, Schritt für Schritt

Diese Seite ist der rechnerische Kern von NeuralMath. Der Code ist klein genug, um vollständig gelesen zu werden, und vollständig genug, um zu zeigen, wie ein neuronales Netz tatsächlich lernt.

1. Daten: ein breiter, aber kontrollierter Bereich

Der Trainingsdatensatz enthält 64 Punkte, der illustrative Testdatensatz 8. Die Punkte sind synthetisch, Masse und Durchmesser bleiben jedoch in plausiblen Bereichen. Eine glatte Referenzkurve dient nur dazu, eine nichttriviale Geometrie zu erzeugen; sie wird dem Netz nicht vorgegeben.

def base_boundary(m):
    return (
        6.68
        + 0.74 * np.exp(-((m - 155) / 20) ** 2)
        + 1.50 / (1 + np.exp(-(m - 202) / 5))
    )

X_train = np.vstack([a1, a2, l1, l2])
y_train = np.array([1.0] * 32 + [0.0] * 32)

2. Standardisierung

Masse und Durchmesser liegen auf unterschiedlichen numerischen Skalen. Deshalb werden Mittelwert und Standardabweichung des Trainingsdatensatzes verwendet, um sowohl Trainings- als auch Testdaten zu transformieren. Die Testdaten bestimmen die Normalisierungsparameter nicht.

mean = X_train.mean(axis=0)
std = X_train.std(axis=0)
Xn = (X_train - mean) / std

3. Architektur: 2–12–1

Zwei Eingaben speisen eine verborgene Schicht mit zwölf ReLU-Neuronen, gefolgt von einem Sigmoid-Ausgang. Damit ergeben sich 49 trainierbare Parameter. Die verborgene Schicht ist ausdrucksstark genug für eine deutlich nichtlineare Grenze und bleibt dennoch überschaubar.

rng = np.random.default_rng(42)
W1 = 0.1 * rng.standard_normal((12, 2))
b1 = np.zeros(12)
W2 = 0.1 * rng.standard_normal(12)
b2 = 0.0

4. Vorwärtsrechnung

Für jede Eingabe berechnet das Netz eine affine Transformation, wendet ReLU an, kombiniert die verborgenen Aktivierungen und verwendet schließlich die Sigmoid-Funktion. Das ist der Vorhersagepfad.

z1 = W1 @ x + b1
h = relu(z1)
z2 = W2 @ h + b2
y_hat = sigmoid(z2)

5. Backpropagation

Der Code differenziert den quadratischen Fehler durch die Sigmoid-Funktion und anschließend durch die ReLU-Schicht. Es wird kein automatisches Differentiationssystem verwendet: Die Kettenregel erscheint explizit im Programm.

delta2 = (y_hat - target) * y_hat * (1 - y_hat)
dW2 = delta2 * h
db2 = delta2

delta1 = (delta2 * W2) * relu_derivative(z1)
dW1 = np.outer(delta1, x)
db1 = delta1

6. Stochastischer Gradientenabstieg

In jeder Epoche werden die Beispiele gemischt. Die Parameter werden nach jedem Beispiel aktualisiert; am Ende der Epoche wird der mittlere Trainingsfehler mit festgehaltenen Parametern neu berechnet.

for epoch in range(n_epochs):
    for i in rng.permutation(len(Xn)):
        # forward pass, backpropagation, update
        W1 -= learning_rate * dW1
        b1 -= learning_rate * db1
        W2 -= learning_rate * dW2
        b2 -= learning_rate * db2

7. Die gelernte Entscheidungsgrenze

Nach dem Training wertet der Code das Netz auf einem dichten Masse–Durchmesser-Gitter aus. Das Niveau ŷ = 0,5 wird zur Entscheidungsgrenze. Alle Trainingspunkte bleiben in der Abbildung sichtbar.

masses = np.linspace(116, 214, 500)
diameters = np.linspace(6.0, 8.85, 500)
M, D = np.meshgrid(masses, diameters)
grid = np.column_stack([M.ravel(), D.ravel()])
P = predict(grid, mean, std, W1, b1, W2, b2).reshape(M.shape)

ax.contour(M, D, P, levels=[0.5], linewidths=2.2)

8. Reproduzierbarkeit

Ein fester Seed macht das Experiment in der dokumentierten NumPy-Umgebung deterministisch. Dasselbe Skript erzeugt die mit dem Projekt verteilte Abbildung.

rng = np.random.default_rng(42)
# The same training-set statistics, initialization,
