Redes neurais, das equações ao código

Leia a rede neural diretamente no código Python.

NeuralMath é uma introdução multilíngue e centrada em código às redes neurais. O website explica passo a passo uma implementação completa em NumPy; os textos pedagógicos mais extensos são disponibilizados separadamente em PDF.

Um exemplo, examinado em profundidade

O site é deliberadamente organizado em torno de um único programa reproduzível. Cada parte do código é ligada à ideia matemática que implementa, sem transformar as páginas web em um segundo livro-texto.

Código primeiro

Comece pelo programa executável e percorra dados, padronização, arquitetura, propagação direta, retropropagação, treinamento e visualização.

Pedagogia em PDF

As explicações matemáticas longas ficam nos PDFs, mantendo o website conciso e útil como companheiro computacional.

Preparado para crescer

Módulos futuros podem reutilizar a mesma estrutura para classificação multiclasse, redes mais profundas, verificação de gradientes, otimização e demonstrações interativas.
