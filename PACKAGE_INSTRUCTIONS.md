# Package assembly

The multilingual NeuralMath site is distributed in a small core ZIP plus four media ZIPs to keep each downloadable artifact below the platform file-size limit.

1. Extract `NeuralMath_website_multilingual_v3_core.zip`.
2. Extract `NeuralMath_website_multilingual_v3_media_01.zip` through `media_04.zip` into the **same parent directory**, allowing the `NeuralMath/` folder to merge.
3. The resulting `NeuralMath/` directory is the complete repository tree and can be committed/pushed to GitHub.

Media groups:
- 01: PT, EN, ES, FR, IT
- 02: DE, AR, BN, CS, EL, FA
- 03: HI, HU, ID, JA, KO, NL
- 04: PL, RO, RU, SV, TR, UK, UR, VI, ZH
